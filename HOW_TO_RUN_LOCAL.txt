========================================
  راهنمای اجرای کامل روی کامپیوتر محلی
  (LSTM + TensorFlow + XGBoost)
========================================

۱. نصب پکیج‌ها
---------------
در پوشه پروژه این دستور را بزنید:

    pip install -r requirements.txt

(اگر GPU دارید می‌توانید tensorflow را با نسخه GPU نصب کنید، ولی اجباری نیست)


۲. تنظیم تلگرام
---------------
یکی از این دو روش را انتخاب کنید:

روش الف) فایل .env بسازید (پیشنهادی):
    - فایل .env.example را کپی کنید و نامش را .env بگذارید
    - داخلش این دو خط را با اطلاعات واقعی پر کنید:

TELEGRAM_BOT_TOKEN=توکن_بات_شما
TELEGRAM_CHAT_ID=آیدی_کانال_یا_چت

روش ب) مستقیم در فایل config.py:
    فایل config.py را باز کنید و این دو خط را پیدا کنید و جایگزین کنید:

TELEGRAM_BOT_TOKEN = "توکن_بات_شما"
TELEGRAM_CHAT_ID = "آیدی_کانال_یا_چت"


۳. اجرا
-------
    python main.py

بعد از اجرا:
- داده‌های تاریخی را از مکسی می‌گیرد
- مدل Hybrid را روی داده‌های قبلی آموزش می‌دهد (چند دقیقه طول می‌کشد)
- پیام «آموزش اولیه تمام شد» به تلگرام می‌فرستد
- از آن به بعد هر ۱۰ دقیقه (دقایق ۰۰، ۱۰، ۲۰، ...) سیگنال می‌دهد


۴. صفحه وضعیت
-------------
مرورگر را باز کنید و بروید به:
    http://localhost:8080

می‌توانید وضعیت مدل، آخرین قیمت و دقت را ببینید.


۵. فایل‌های مهم
---------------
- config.py          → تنظیمات + توکن تلگرام
- .env               → توکن تلگرام (روش بهتر)
- main.py            → برنامه اصلی
- utils/models.py    → مدل Hybrid (LSTM + XGBoost)
- utils/features.py  → تمام اندیکاتورها
- data/predictor.db  → دیتابیس محلی (خودکار ساخته می‌شود)
- models/            → فایل‌های مدل ذخیره‌شده


نکته:
اگر بار اول آموزش طول کشید صبر کنید. بعد از اولین آموزش، مدل در پوشه models ذخیره می‌شود و دفعات بعد سریع‌تر لود می‌شود.
